# MooGold MLBB price bot

Telegram bot (webhook mode) for Render.
Commands: /start /prices /price 5 /check /myid /session_check (admin)

Render settings
- Build Command: pip install -r requirements.txt
- Start Command: python bot_render.py
- Environment variables: BOT_TOKEN, WEBHOOK_SECRET, ADMIN_ID, MONGODB_URI

Never commit tokens, MongoDB URI or session files.
